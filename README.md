# PDF_Summarizer
📄 Intelligent Document Retrieval & QA System (RAG)

A Retrieval-Augmented Generation (RAG) application that enables semantic search and context-aware question answering over uploaded PDF documents. The system converts unstructured documents into vector embeddings and retrieves relevant context to generate accurate responses.

🔗 Live Demo: https://summarize-your-pdf.streamlit.app/

🚀 Features

Upload and query PDF documents interactively

Semantic search using vector embeddings

Context-aware multi-turn conversations

Document-grounded responses (reduces hallucinations)

Fast retrieval over large documents


⚙️ Tech Stack

Python

LangChain

FAISS (Vector Database)

Hugging Face Transformers

Streamlit

LLM API (OpenAI / HF inference)
